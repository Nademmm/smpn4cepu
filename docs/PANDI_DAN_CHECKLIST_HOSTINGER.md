## BAGIAN 2: Checklist Pembelian & Setup Awal di hPanel Hostinger

### 1. Saat Checkout Keranjang Hostinger
- [ ] **Akun Email Hostinger:** Pastikan login ke Hostinger menggunakan email resmi sekolah (misalnya `smpn4cepu@gmail.com`) atau email yang disepakati dengan klien agar pengingat perpanjangan tahun depan masuk ke sekolah.
- [ ] **Durasi & Paket:** Paket **Cloud Startup (12 Bulan)** + Domain **`smpn4cepu.sch.id` (Gratis 1 Tahun)** + **Backup Harian (Gratis)**.
- [ ] **Klaim Domain & Isi Data Registrant:**
  - Begitu pembayaran berhasil, klik **Setup / Klaim Domain `smpn4cepu.sch.id`**.
  - Isi Nama, Alamat, Email, Nomor Telepon, dan NIK sesuai KTP Penanggung Jawab.
  - Unggah berkas PDF/JPG (KTP, SK Pendirian Sekolah/NPSN, dan Surat Permohonan Kepala Sekolah) pada menu verifikasi domain di hPanel.

### 2. Sambil Menunggu Domain `.sch.id` Aktif (1–3 Hari Kerja), Setup Server Cloud Startup!
Anda **tidak perlu menunggu domain disetujui PANDI** untuk mulai men-deploy aplikasi! Hostinger menyediakan **Temporary Domain (Domain Sementara, misal `*.hostingersite.com`)** dan **Akses SSH via IP Dedicated**.

Lakukan konfigurasi berikut di **hPanel Hostinger**:

#### A. Konfigurasi Versi PHP & Ekstensi (`Wajib!`)
1. Masuk ke **hPanel → Websites → Kelola → Tingkat Lanjut (Advanced) → Konfigurasi PHP**.
2. Pilih versi **PHP 8.2** atau **PHP 8.3** *(Jangan pilih PHP 8.4 karena `filament-shield` di `composer.lock` mengunci versi PHP pada `^8.2|^8.3`)*.
3. Masuk ke tab **Ekstensi PHP (PHP Extensions)**, pastikan ekstensi berikut tercentang:
   - `intl` (Wajib untuk format tanggal Indonesia & Filament)
   - `gd` & `exif` (Wajib untuk upload gambar berita/guru/fasilitas)
   - `zip` & `bcmath`
   - `pdo_mysql` & `mysqli`
   - `opcache`
4. Klik **Simpan Perubahan**.

#### B. Buat Database MySQL / MariaDB Produksi
1. Masuk ke **hPanel → Databases → Pengelolaan MySQL**.
2. Buat database baru:
   - **Nama Database:** `uXXXXXXX_smp4cepu`
   - **Username:** `uXXXXXXX_admin`
   - **Password:** Buat password kuat dan catat untuk dimasukkan ke `.env`.

#### C. Aktifkan Akses SSH
1. Masuk ke **hPanel → Tingkat Lanjut (Advanced) → Akses SSH**.
2. Klik **Enable (Aktifkan)** dan atur password SSH (atau tambahkan SSH Public Key Anda).
3. Salin perintah koneksi SSH yang tertera di layar, contoh:
   ```bash
   ssh -p 65002 u123456789@123.45.67.89
   ```

## BAGIAN 3: Eksekusi Deployment Satu Pintu di SSH Hostinger

Setelah masuk ke terminal SSH Hostinger, jalankan urutan perintah berikut:

```bash
# 1. Masuk ke folder domain utama
cd ~/domains/smpn4cepu.sch.id/

# 2. Clone repositori GitHub ke folder privat 'laravel_app'
git clone https://github.com/<username-github-anda>/smpn4cepu.git laravel_app
cd laravel_app

# 3. Buat file .env produksi dari .env.example
cp .env.example .env
nano .env
```

Ubah isi `.env` pada bagian berikut:
```dotenv
APP_NAME="SMP Negeri 4 Cepu"
APP_ENV=production
APP_KEY=
APP_DEBUG=false
APP_URL=https://smpn4cepu.sch.id
APP_TIMEZONE="Asia/Jakarta"

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=uXXXXXXX_smp4cepu
DB_USERNAME=uXXXXXXX_admin
DB_PASSWORD="PasswordDatabaseHostingerAnda"

SESSION_DRIVER=database
SESSION_SECURE_COOKIE=true
FILESYSTEM_DISK=public
QUEUE_CONNECTION=database
CACHE_STORE=database
```
Simpan file `nano` (`Ctrl+O`, `Enter`, lalu `Ctrl+X`), kemudian jalankan script deployment otomatis:

```bash
# 4. Generate APP_KEY dan jalankan deploy.sh
php artisan key:generate
chmod +x deploy.sh
./deploy.sh
```

### Apa yang Otomatis Dilakukan oleh `./deploy.sh` yang Sudah Diperbarui?
1. Menginstal seluruh paket Composer produksi (`--no-dev --optimize-autoloader`).
2. Mem-build ulang aset Vite (jika Node.js aktif) atau langsung menggunakan *pre-built bundle* di `public/build/manifest.json` yang sudah disertakan di Git (sehingga bebas error `ViteManifestNotFoundException`).
3. Menjalankan migrasi tabel ke MariaDB/MySQL (`php artisan migrate --force`).
4. Mengecek isi database: jika baru pertama kali dipasang (tabel guru/berita masih kosong), **otomatis menjalankan `DatabaseSeeder`** berisi data resmi 609 siswa aktif (20 rombel), 33 GTK SMPN 4 Cepu, 11 fasilitas, 11 mapel, visi-misi, akun role, dan bank soal CBT.
5. Menyalin seluruh foto bawaan dari `public/images/{staff,facilities,principal,assets}` ke `storage/app/public/` dan membuat `storage:link` agar tidak ada gambar yang *broken* (404).
6. Mengubah `../public_html` menjadi *symlink* aman yang mengarah ke `laravel_app/public` (sehingga file `.env` dan kode sumber Laravel berada di luar `public_html` dan 100% aman dari publik).
7. Mengoptimalkan cache Laravel, Filament, Livewire, serta membersihkan LiteSpeed Cache.

## BAGIAN 4: Setup Email Resmi Sekolah & SSL (Setelah Domain Disetujui PANDI)

Begitu PANDI menyetujui dokumen domain `smpn4cepu.sch.id`:
1. **Pastikan Nameserver Mengarah ke Hostinger:**
   - `ns1.dns-parking.com`
   - `ns2.dns-parking.com`
   *(Jika domain dibeli langsung satu keranjang dengan Hostinger seperti di screenshot, DNS ini sudah otomatis terpasang).*
2. **Verifikasi SSL HTTPS Otomatis:**
   - Buka **hPanel → Tingkat Lanjut → SSL**, pastikan status SSL untuk `smpn4cepu.sch.id` sudah **Active (Aktif)** dan aktifkan toggle **Force HTTPS**.
3. **Buat Akun Email Resmi Sekolah (Gratis di Paket Startup):**
   - Buka menu **Emails (Email)** di hPanel Hostinger.
   - Buat mailbox resmi: `smpn4cepu@smpn4cepu.sch.id` atau `admin@smpn4cepu.sch.id`.
   - Masukkan kredensial SMTP email tersebut ke `.env` (`MAIL_USERNAME` & `MAIL_PASSWORD`) jika ingin mengaktifkan pengiriman email dari portal sekolah.
